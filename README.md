# Tkinter GUI exercises

A series of Python Tkinter exercises covering layouts, buttons, input, a simple calculator, icons, images, and message boxes.

Use Python 3 with Tkinter available. Start with the Part 01 source and run each exercise from the repository root so its local assets can be found. The Pillow image exercise also needs Pillow.

## Exercises
